## Why Include?

Every launch file in this module starts turtlesim the same way. Copying that block into each file means a change (a background colour, a new node) has to be repeated everywhere. `IncludeLaunchDescription` lets one launch file **call** another, like a function call:

```
circle_args.launch.py
    ├── includes  sim.launch.py   (turtlesim + goal_point_publisher)
    └── adds      circle_publisher
```

The included file is a normal launch file you can also run alone.

---

## Concept: Including a Launch File

```python
from launch.actions import IncludeLaunchDescription
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch.substitutions import PathJoinSubstitution
from launch_ros.substitutions import FindPackageShare

sim = IncludeLaunchDescription(
    PythonLaunchDescriptionSource(
        PathJoinSubstitution([
            FindPackageShare('turtlesim_controller'),
            'launch',
            'sim.launch.py',
        ])
    ),
    launch_arguments={'background_b': '120'}.items(),
)
```

- `PythonLaunchDescriptionSource` reads a `.launch.py` file; there are XML and YAML sources for other formats
- The path uses the substitutions from 5.4, so it works from any working directory once installed
- `launch_arguments` is an **iterable of `(name, value)` pairs**, which is why a dict needs `.items()`. Values are strings
- The include is an *action*: it goes in the `LaunchDescription` list

**Arguments reach only what declares them.** `launch_arguments={'background_b': '120'}` works because `sim.launch.py` declares `background_b`. If the included file declares no such argument, the pair is silently ignored. Give every argument a default so the included file also works alone.

## Step 1 — Extract `sim.launch.py`

Create `launch/sim.launch.py` with turtlesim and the goal GUI, and a `background_b` argument that sets the turtle window's blue channel:

```python
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.substitutions import LaunchConfiguration
from launch_ros.actions import Node
from launch_ros.parameter_descriptions import ParameterValue


def generate_launch_description():
    background_b_arg = DeclareLaunchArgument(
        'background_b',
        default_value='255',
        description='Blue channel of the turtlesim background (0-255)',
    )

    turtlesim_node = Node(
        package='turtlesim',
        executable='turtlesim_node',
        name='turtlesim',
        output='screen',
        parameters=[{
            'background_b': ParameterValue(
                LaunchConfiguration('background_b'), value_type=int),
        }],
    )

    goal_point_publisher = Node(
        package='goal_point_publisher',
        executable='goal_point_publisher',
        name='goal_point_publisher',
        output='screen',
    )

    return LaunchDescription([
        background_b_arg,
        turtlesim_node,
        goal_point_publisher,
    ])
```

Build, then test it on its own:

```bash
cd ~/tutorial_ws
colcon build --packages-select turtlesim_controller
source ~/tutorial_ws/install/setup.bash
ros2 launch turtlesim_controller sim.launch.py background_b:=60
```

The turtlesim window is darker and the goal GUI opens. Stop it (`Ctrl+C`).

## Step 2 — Include It

Rewrite `circle_args.launch.py`: remove its own turtlesim `Node`, and include `sim.launch.py` instead. Keep the `radius` and `angular_speed` arguments, and add a pass-through argument `background_b`:

```python
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument, IncludeLaunchDescription
from launch.launch_description_sources import PythonLaunchDescriptionSource
from launch.substitutions import LaunchConfiguration, PathJoinSubstitution
from launch_ros.actions import Node
from launch_ros.parameter_descriptions import ParameterValue
from launch_ros.substitutions import FindPackageShare


def generate_launch_description():
    radius_arg = DeclareLaunchArgument('radius', default_value='1.0')
    speed_arg = DeclareLaunchArgument('angular_speed', default_value='1.0')
    background_arg = DeclareLaunchArgument('background_b', default_value='255')

    sim = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            PathJoinSubstitution([
                FindPackageShare('turtlesim_controller'),
                'launch',
                'sim.launch.py',
            ])
        ),
        launch_arguments={
            'background_b': LaunchConfiguration('background_b'),
        }.items(),
    )

    circle_publisher = Node(
        package='turtlesim_controller',
        executable='circle_publisher',
        name='circle_publisher',
        output='screen',
        parameters=[{
            'radius': ParameterValue(
                LaunchConfiguration('radius'), value_type=float),
            'angular_speed': ParameterValue(
                LaunchConfiguration('angular_speed'), value_type=float),
        }],
    )

    return LaunchDescription([
        radius_arg,
        speed_arg,
        background_arg,
        sim,
        circle_publisher,
    ])
```

Note that `launch_arguments` accepts a substitution as a value, so the outer file's argument is forwarded to the inner one.

Rebuild and launch:

```bash
cd ~/tutorial_ws
colcon build --packages-select turtlesim_controller
source ~/tutorial_ws/install/setup.bash
ros2 launch turtlesim_controller circle_args.launch.py radius:=2.0 background_b:=60
```

The turtle draws a circle of radius 2.0 in a darker window, and the goal GUI is open. Confirm the node graph:

```bash
ros2 node list
# /circle_publisher
# /goal_point_publisher
# /turtlesim
```

Include is **transparent**: the included nodes appear in the same graph as if they were declared in the outer file.

## Exercise

**Description**

Add a `background_r` argument (default `'69'`) to `sim.launch.py`, set as the turtlesim parameter `background_r`. Forward it from `circle_args.launch.py` through `launch_arguments`.

**Requirements**

- `ros2 launch turtlesim_controller sim.launch.py --show-args` lists `background_r` and `background_b`
- `circle_args.launch.py background_r:=200` gives `ros2 param get /turtlesim background_r` = `200`
- Running `sim.launch.py` alone still works with default colours

---

## Answer Key

In `sim.launch.py`, add the declaration and the parameter (as `int`):

```python
    background_r_arg = DeclareLaunchArgument('background_r', default_value='69')
```

```python
        parameters=[{
            'background_r': ParameterValue(
                LaunchConfiguration('background_r'), value_type=int),
            'background_b': ParameterValue(
                LaunchConfiguration('background_b'), value_type=int),
        }],
```

Add `background_r_arg` to the `LaunchDescription` list.

In `circle_args.launch.py`, declare `background_r` with the same default and forward it:

```python
        launch_arguments={
            'background_r': LaunchConfiguration('background_r'),
            'background_b': LaunchConfiguration('background_b'),
        }.items(),
```

Each layer declares the argument (so it appears in `--show-args` and has a default) and forwards it (so it reaches the inner file).

---

## Summary

| Concept | Key point |
|---|---|
| `IncludeLaunchDescription` | Runs another launch file as an action |
| `PythonLaunchDescriptionSource(path)` | Source for `.launch.py` files; build the path with `FindPackageShare` |
| `launch_arguments={...}.items()` | Passes arguments to the included file; values may be substitutions |
| Defaults | An included file's arguments need defaults so it also works alone |
| Transparent | Included nodes join the same graph; namespaces are not added unless you use `GroupAction` |
